# rime-config
适用于macOS、iOS、iPadOS和Android的Personal Rime配置，提供统一的输入体验和自动部署功能。




###
```shell
  brew install jsonnet fswatch rclone
```



###

```
rime-dotfiles/
├── shared/       # 雾凇拼音、词库、Lua 脚本
├── macos/        # 鼠须管
├── ios/          # 元书（iPhone、iPad）
├── android/      # 同文输入法
├── scripts/      # 编译、同步、部署脚本
└── README.md
```
